# TechPath

## About The Project

TechPath is a web application designed to help people discover suitable technology career paths and create practical learning roadmaps.

It serves both beginners who want to enter the technology industry and existing professionals who want to advance or transition into different roles.

## Problem Statement

The technology industry offers many career options, which can make it difficult for people to decide where to begin, which skills to learn, and how to progress.

TechPath aims to make this journey clearer by providing personalized career recommendations and structured learning roadmaps.

## Planned Features

-Career discovery questionnaire
-Technology career recommendations
-Career information and required skills
-Step-by-step learning roadmaps
-Learning progress tracking
